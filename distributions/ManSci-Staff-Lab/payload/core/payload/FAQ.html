Installation

What should I install?

ManSci Complete installs Core and configures all three tools. Core creates the mansci-python environment, kernel, shared folder, examples, local Qwen model and this Help launcher. Individual tool installers include and verify the same Core.

Before starting

  • Extract the entire ZIP to a normal local folder.
  • Keep an internet connection and several GB of free space.
  • Close ManSci tools before updating.
  • Keep the installer window open and respond to prompts. Conda solving and the roughly 2 GB model download can take many minutes.
  • For Ollama choose local use; no account or terminal command is required.

How do I know it finished?

Do not assume that a closed or quiet window means success. Look for INSTALLATION COMPLETE. If it says installation not complete, preserve the displayed log location and use the guidance below.

Everyday working

All tools use mansci-python and Documents/ManSci Code, so code and data can move between Spyder, Lab and VS Code. Keep programme work in this folder and back up important files.

To change the shared folder, put one absolute folder path in Documents/ManSci Code Home.txt, save it, and restart all tools. Existing work is not moved automatically.

  • Spyder: suited to Python scripts and #%% cells. Files opens in the shared folder.
  • ManSci Lab: suited to notebooks. Closing its window normally leaves the local server and kernels running for quick reconnection. Use File → Shut Down to stop them.
  • ManSci VS Code: uses an isolated teaching profile. It should not alter ordinary VS Code.

Mac questions

“Apple could not verify…”

This expected message means our installer has not been Apple Developer ID-signed and notarised; it does not itself mean malware was detected. Only proceed for a ZIP obtained through the teaching team’s GitHub link.

  1. Click Done, not Move to Bin.
  2. Open System Settings → Privacy & Security.
  3. Under Security, find the blocked installer and click Open Anyway.
  4. Authenticate and confirm Open. Do not disable general security protections.

Stop if macOS explicitly says malware was detected or the software will damage your computer. Contact the teaching team. That is a different warning.

Close versus Quit

The red button closes a window but often leaves the application active. Use Command-Q to quit completely.

Putting ManSci VS Code in the Dock

  1. Quit VS Code.
  2. Remove an existing ordinary VS Code Dock item if necessary.
  3. In Finder open your home folder’s Applications folder.
  4. Drag ManSci VS Code.app into the Dock.

Do not choose Keep in Dock on Microsoft VS Code’s running icon: macOS then saves the ordinary Microsoft application, which cannot remember the ManSci launch settings after Quit. While running, Microsoft’s icon may appear separately.

An empty VS Code window appears after red-close

Clicking the still-running Dock icon should reopen the shared folder. If it does not, use the pinned ManSci launcher or choose File → Open Folder and open Documents/ManSci Code.

Windows questions

Mac Open Anyway steps do not apply. Windows may show its own security, firewall or permission prompts; a permission prompt is not proof that software is safe. Contact staff about unexpected warnings.

Taskbar pins

Open Start, find ManSci Spyder, ManSci Lab or ManSci VS Code, right-click and choose Pin to taskbar (possibly under More). Pin the ManSci entry, not an ordinary Python/VS Code icon. The installer never changes pins automatically. After launcher updates, unpin an old item and repin the new Start entry.

Firewall prompt for VS Code

Local scripts and notebooks do not normally require inbound public-network access. Cancel the prompt unless your course specifically requires network sharing. Web requests made by your own code are separate.

Python, cells and notebooks

  • The interpreter should be from the mansci-python environment.
  • The notebook kernel should be Management Science Python.
  • In Spyder, Ctrl/Command-Enter runs the current cell; Shift-Enter runs and advances when that shortcut is assigned.
  • The displayed %runcell line is Spyder’s record of how a cell was executed, not an error.
  • A Jupyter “not trusted” message concerns whether saved notebook output may run active content. It does not mean the Python code failed.

If a kernel/interpreter is missing, close the tool and rerun its latest installer to completion. Do not create another similarly named environment. Staff may ask you to run student-profile-check.py from the shared folder.

Local AI assistant

Qwen2.5-Coder 3B runs locally through Ollama. It needs no shared key or account. The first response can be slow—especially in a VM or with limited memory—and a small model can misunderstand context or produce incorrect code. Review and test everything it suggests.

  • Give explicit context: say Python, describe the required input/output, and paste the relevant code when necessary.
  • In VS Code use the ManSci-configured Continue interface, not GitHub Copilot sign-in.
  • In Lab choose the configured local persona/model. Recent chat context is retained, but the model does not automatically understand every open notebook cell.

Repair, reinstall and contact staff

Reinstalling updates the environment and permanent launchers; it should not delete files in ManSci Code, chats or downloaded Ollama models. Always extract a newly downloaded ZIP rather than running an old extracted installer.

Logs

  • Windows: %LOCALAPPDATA%\ManagementScience\Logs
  • Mac: ~/Library/Logs/ManagementScience

What to send the teaching team

  1. Your operating system, Mac chip or Windows architecture, and whether it is a VM.
  2. The installed release shown at the top of this page.
  3. The exact action and complete error message or screenshot.
  4. The newest installation/launch log and, if requested, the output from student-profile-check.py.
  5. Whether the installer ended with INSTALLATION COMPLETE.

Do not send passwords, API keys, notebook access tokens, confidential data or unrelated personal files.
