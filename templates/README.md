# PowerPoint source template

`UCL-PowerPoint-Template-UCL-Sans.pptx` is the recovered, editable copy of the UCL template supplied by the module lead. All generated PowerPoint teaching assets must be built from this file and retain its masters, layouts, theme, UCL Sans references and logos.

Run `python tools/validate_ucl_powerpoint.py <deck.pptx> [...]` before packaging or publishing a deck. A visual imitation of the colours or logo does not satisfy this requirement.
