# ManSci Staff Lab

Staff-only JupyterLab with Azure OpenAI GPT-4.1, the ManSci Learning Assistant and local Qwen2.5-Coder 3B, using the same `mansci-python` environment, **Management Science Python** kernel and `Documents/ManSci Code` folder as the student tools.

This package contains no Azure credentials. Extract the complete ZIP and run:

- Windows: **Install-Windows.bat**
- Mac: **Install-Mac.command**

The guided installer checks prerequisites, updates/reuses Core, asks for and tests Azure details when needed, stores the key in the operating-system credential store, then creates **ManSci Staff Lab** on the Desktop and application menu. Keep the installer open until it reports **INSTALLATION COMPLETE**.

Read **STAFF-LAB-GUIDE.md** before installing. General offline guidance is installed as **ManSci Help**. Credential reset and chat-repair scripts are under **Support Tools**.

Do not distribute an Azure key. Azure requests may incur charges.
