## How the team maintains this file

1. One rotating context steward edits the agreed master after a meaningful whole-team review.
2. The team checks the update and clearly identifies the latest agreed version above.
3. On the ManSci VM, share a dated snapshot through **Team Exchange**. Other members use **Copy to My Work** before editing or using a snapshot.
4. Avoid parallel competing masters. If two versions exist, resolve them in a whole-team review and record the decision.
5. Attach the latest agreed file when starting an external AI chat. With the ManSci Learning Assistant, ask it to read the saved file and identify gaps, conflicts or stale assumptions.
6. Treat AI suggestions as proposals. The team verifies evidence and decides whether to update this record.
7. Do not include passwords, API keys, personal data or restricted material.
